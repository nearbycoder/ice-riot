# ICE RIOT — Audio Contract

All audio is ORIGINAL and generated by `Tools/gen_audio.py` (numpy synthesis; Blender's bundled Python has numpy:
`/Applications/Blender.app/Contents/Resources/5.3/python/bin/python3.13`). Announcer lines use macOS `say`
(pick the most energetic, clear voice available via `say -v '?'`; post-process with EQ, compression, light
saturation and a short arena slap-back so it sounds like a PA announcer). Output 48 kHz 16-bit WAV in
`Art/Export/Audio/<Category>/<Name>.wav`. `Tools/ue_import_audio.py` (run headless via the editor's python
commandlet) imports them to `/Game/IceRiot/Audio/<Category>/<Name>` as SoundWaves (loops flagged `bLooping`) and
creates SoundClasses `SC_Master` → `SC_Music`, `SC_SFX`, `SC_Crowd`, `SC_Announcer`, `SC_UI` assigned by category.

Reference implementation (different sport, same machine/tools): `/Users/nearby/.t3/projects/basketballjam/Tools/gen_audio.py`.
Reuse DSP techniques, never its lines/branding. No real league/team/player/brand names; never say "Zamboni".

Variations: names ending in `_NN` are variations the game picks randomly — provide the listed count.
